Transparent by design. How are these signals calculated?

Missing values: empty cells and the tokens NA, N/A, null, none, and NaN (case-insensitive, trimmed). Duplicates: exact cell strings, counting repeats after the first occurrence. Numeric columns: every nonmissing cell must be a finite decimal or scientific-notation number. Outliers: values outside Q1 − 1.5 × IQR and Q3 + 1.5 × IQR using interpolated quartiles; skipped when IQR is zero. Identifiers may be inferred as numeric. Dates are not inferred.

This version inspects data and previews opt-in cleaning steps, exporting a separate CSV and transformation log. It does not identify leakage or provide an ML readiness score. Browser analysis uses a separate JavaScript implementation of the Python core.
